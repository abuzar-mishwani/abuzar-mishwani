### Qistora — Financing OS for Mobile Devices

- **Role:** Founder and Lead Developer
- **Status:** Production
- **Stack:** Android Device Owner (DPC) · Kotlin · MDM Infrastructure
- **Live:** [qistora.app](https://qistora.app)
